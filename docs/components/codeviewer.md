# CodeViewer  (type: 'codeviewer')
Purpose:       Shows source code, read-only: syntax colors, line numbers, highlighted lines and a copy button. For docs, settings screens that show a snippet or a key, logs.
Anatomy:       `.op-codeviewer` > `.op-codeviewer__bar` (`__title` and the copy `.op-button`) and `pre.op-codeviewer__pre` (focusable: it scrolls) > `code` > one `.op-codeviewer__line` per line (`is-marked` on highlighted lines) holding `.op-codeviewer__tok--<kind>` spans (`keyword`, `string`, `comment`, `number`, `property`, `tag`, `attr`). Line numbers are CSS counters, so a selection copies only the code.
Config:        `code: ''`, `language: 'ts'` (`'ts' | 'js' | 'json' | 'css' | 'html' | 'sh' | 'text'`), `title` (the bar text; default: the language name), `lineNumbers: true`, `startLine: 1`, `highlight` (lines to mark: `[3, 4]` or `'3-5,8'`), `wrap: false` (long lines wrap instead of scrolling), `copyable: true` (the copy button), `bar: true` (the title bar), `maxHeight` (beyond it the code scrolls).
API:           `getCode()`, `setCode(code)`, `setLanguage(lang)`, `setTitle(text)`, `setLineNumbers(bool)`, `setStartLine(n)`, `setHighlight(lines)`, `setWrap(bool)`, `copy(): Promise<boolean>` (false when there is no clipboard: the code is then selected, ready for Ctrl+C).
Events:        `copy(code)` after the code reaches the clipboard.
States:        `has-numbers`, `is-wrapped`; the copy button says "Copied" with a check for a moment (and announces it).
Keyboard/ARIA: The `pre` is a tab stop (`tabindex=0`, named by the title) so it can be scrolled with the keyboard; line numbers are not in the text, so screen readers read only the code; the copy button has a name and its result goes to a polite live region.
Tokens:        `--op-codeviewer-bg`, `--op-codeviewer-fg`, `--op-codeviewer-font-size`, `--op-codeviewer-line-height`, `--op-codeviewer-gutter-fg`, `--op-codeviewer-mark-bg`, `--op-codeviewer-keyword`, `--op-codeviewer-string`, `--op-codeviewer-comment`, `--op-codeviewer-number`, `--op-codeviewer-property`, `--op-codeviewer-tag`, `--op-codeviewer-tab-size`, `--op-codeviewer-max-height`, `--op-codeviewer-gutter-gap`.
Sandbox cases: TypeScript with marked lines, JSON, CSS, HTML, a shell command without numbers or bar, wrapping vs scrolling, a long file with `maxHeight`, `startLine` (an excerpt).
Out of scope:  editing (a code editor), full grammars (it is a small, safe highlighter: it never builds HTML from the code), diffs, folding, line links.
