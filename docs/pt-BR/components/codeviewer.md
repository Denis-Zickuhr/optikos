# CodeViewer  (type: 'codeviewer')
Propósito:     Mostra código-fonte, só leitura: cores de sintaxe, números de linha, linhas destacadas e um botão de copiar. Para docs, telas de configuração que mostram um trecho ou uma chave, logs.
Anatomia:      `.op-codeviewer` > `.op-codeviewer__bar` (`__title` e o `.op-button` de copiar) e `pre.op-codeviewer__pre` (focável: ele rola) > `code` > um `.op-codeviewer__line` por linha (`is-marked` nas linhas destacadas) com spans `.op-codeviewer__tok--<tipo>` (`keyword`, `string`, `comment`, `number`, `property`, `tag`, `attr`). Os números de linha são contadores CSS, então uma seleção copia só o código.
Config:        `code: ''`, `language: 'ts'` (`'ts' | 'js' | 'json' | 'css' | 'html' | 'sh' | 'text'`), `title` (o texto da barra; padrão: o nome da linguagem), `lineNumbers: true`, `startLine: 1`, `highlight` (linhas a destacar: `[3, 4]` ou `'3-5,8'`), `wrap: false` (linhas longas quebram em vez de rolar), `copyable: true` (o botão de copiar), `bar: true` (a barra de título), `maxHeight` (além disso o código rola).
API:           `getCode()`, `setCode(code)`, `setLanguage(lang)`, `setTitle(texto)`, `setLineNumbers(bool)`, `setStartLine(n)`, `setHighlight(linhas)`, `setWrap(bool)`, `copy(): Promise<boolean>` (false quando não há área de transferência: o código fica selecionado, pronto para Ctrl+C).
Eventos:       `copy(code)` depois que o código chega à área de transferência.
Estados:       `has-numbers`, `is-wrapped`; o botão de copiar mostra "Copiado" com um check por um instante (e anuncia).
Teclado/ARIA:  O `pre` é uma parada de Tab (`tabindex=0`, nomeado pelo título) para rolar pelo teclado; os números de linha não fazem parte do texto, então leitores de tela leem só o código; o botão de copiar tem nome e o resultado vai para uma região viva educada.
Tokens:        `--op-codeviewer-bg`, `--op-codeviewer-fg`, `--op-codeviewer-font-size`, `--op-codeviewer-line-height`, `--op-codeviewer-gutter-fg`, `--op-codeviewer-mark-bg`, `--op-codeviewer-keyword`, `--op-codeviewer-string`, `--op-codeviewer-comment`, `--op-codeviewer-number`, `--op-codeviewer-property`, `--op-codeviewer-tag`, `--op-codeviewer-tab-size`, `--op-codeviewer-max-height`, `--op-codeviewer-gutter-gap`.
Casos sandbox: TypeScript com linhas destacadas, JSON, CSS, HTML, um comando de shell sem números nem barra, quebra vs rolagem, um arquivo longo com `maxHeight`, `startLine` (um trecho).
Fora do escopo: edição (um editor de código), gramáticas completas (é um destacador pequeno e seguro: nunca monta HTML a partir do código), diffs, dobras, links de linha.
